# Three.js model setup

This branch uses Three.js + GLTFLoader for the interactive hero.

Place the supplied GLB avatar at:

`public/nithish-model.glb`

The scene automatically:
- enters from below and scales into place
- rotates the model gently
- responds to pointer movement
- renders an atmospheric particle field and orbit rings
- adapts to desktop and mobile sizes

The current conversation preview already contains the supplied GLB alongside the standalone preview.

No deployment is configured by this change.
